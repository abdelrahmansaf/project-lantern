# PROJECT LANTERN

**Classification:** Restricted  
**Case ID:** LTN-001

A repository was recovered after an unexplained interruption.

Its source code is incomplete. Its history is unreliable. Its final destination is unknown.

Your task is to reconstruct the chain of evidence.

## Rules of engagement

1. Every stage produces an identifier required by the next.
2. Do not assume that the latest information is necessarily correct.
3. Every conclusion must be supported by evidence.
4. The final code must be sent to the contact address revealed at the end.

No password guessing is required. Every puzzle has a logically verifiable solution.
